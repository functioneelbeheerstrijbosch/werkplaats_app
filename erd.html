ERP Sync

BigQuery (Drive_Werkplaats_App_native)
    │
    │  Cloud Run (main.py) — elke X minuten
    │  1. Query BigQuery
    │  2. Upsert → reparaties (on_conflict: opdrachtnr + regelnummer)
    │  3. Verdwenen opdrachtnrs → log in reparatie_logs (SYS) + delete
    ▼
reparaties (Supabase)

Statusflow reparaties

445 (Openstaand)
    │
    │  Monteur claimt / Manager wijst toe
    ▼
465 (In behandeling)
    │
    │  Monteur rondt af
    ▼
519 (Afgerond)
    │
    │  ERP sync verwijdert na export
    ▼
(verwijderd uit reparaties, log blijft in reparatie_logs)
